# PP & Prosper SME 报价器 Core Reliability Repair v1

## 验证结论

本轮 v4 已完成可执行的 Core Reliability 修复并通过核心规则、导出模型、XLSX 二进制和浏览器加载验证。本次业务规则更正已删除旧版错误的 Plan 3 全球变体；Plan 3 仅保留 WWE，Plan 4 保留 WW 与 WWE。本轮新增并验证三项可选报价规则：门诊第 6 次起就诊自付 20%（指定的 PCP、互联网问诊和慢病送药不计入门诊次数，Medical 保费下调 6%）；柏盛 PCP 首诊直付服务（急诊除外，Medical 保费下调 6%）；最高等级 FMU（11EE 以下全员个人健康告知、不承担一切既往症，Medical 保费下调 5%）。三项医疗折扣可以按选择叠加，折扣金额与最终个人保费按人民币常规四舍五入至整元。

本报告不把浏览器环境未暴露 Blob 下载事件记为“下载通过”；同一导出路径生成的 XLSX 已通过 SheetJS 回读、ZIP 完整性检查和 openpyxl 结构检查。

## 变更范围

- 计划模型仅保留 `P3WWE`、`P4WWE`、`P4WW` 的正式 Plan 3/Plan 4 区域组合，并为每个计划保留 `code`、`group`、`area`、`rateColumn`、`outpatientMaximum` 和源表定位信息。
- 年龄/费率路径实现 `AUTO_QUOTABLE`、`MANUAL_RATE`、`PENDING_UW`、`INELIGIBLE`；65–69 岁可自动报价，70 岁以上或缺失年龄进入待人工费率；人工医疗费率计入总保费，待人工费率不计入且不以静默 0 代替；子女最大年龄为 25 岁。
- 福利表被规范化为结构化 `Benefit Data`，保留双语责任、各真实计划/区域组合、共享责任组、源工作表和源行号；理疗/中医/中草药、体检/免疫、牙科共享组与生育、妊娠并发症独立责任分开表达。
- Compare 使用同一批人员跨方案比较；Group 按唯一 `Plan` 计算限制，同一 Plan 的多个福利变体不重复计数；生育三年不可变更仅作提示。
- 自付比例在第一部分以全局勾选项提供；未勾选为标准 0%，勾选“门诊第 6 次起就诊自付 20%”使所有当前及后续报价变体的 Medical 保费下调 6%，并在 UI、报价表和 TOB 中保留 PCP、互联网问诊、慢病送药不计入门诊次数的保障说明。
- 柏盛 PCP 首诊直付服务为独立的全局可选项，明确“需通过柏盛 PCP 首诊方可涵盖直付服务；急诊除外”，可与门诊自付比例同时选择，Medical 保费下调 6%。
- 最高等级 FMU 在第一部分以全局勾选项提供，明确 11EE 以下全员提供个人健康告知、不承担一切既往症，Medical 保费下调 5%。
- 第一部分“报价信息”集中呈现三个独立勾选项：柏盛 PCP 首诊直付、门诊第 6 次起自付 20%和最高等级 FMU；第二部分仅保留报价方案名称与可选福利组合，不按方案重复选择上述核心条件。
- Medical 折扣按每位被保险人的正式医疗费率计算，折扣金额及个人最终保费按人民币常规四舍五入至整元，再汇总到报价页，确保个人明细与方案合计一致。
- `费率 Premium` 使用与个人保费相同的 Medical 折扣计算，并同时展示调整后每人医疗费率与原始源费率；源费率仅作审计对照，不被覆盖。
- XLSX 输出包含报价、费率、每个方案 TOB、HCP、参保条件、预授权和重大既往症工作表，不包含增值服务工作表；正式 XLSX 同时使用统一标题色、分组色、边框、换行、列宽、行高和人民币金额格式。
- 构建脚本将 CSS、核心规则、浏览器应用、本地 SheetJS 和本地 JSZip 组件内嵌为单文件；无服务端、无 CDN、无运行时网络依赖。
