## 验证结论

本轮 v4 已完成可执行的 Core Reliability 修复并通过核心规则、导出模型、XLSX 二进制和浏览器加载验证。本次业务规则更正已删除旧版错误的 Plan 3 全球变体；Plan 3 仅保留 WWE，Plan 4 保留 WW 与 WWE。本轮已确认并验证三项可选报价规则：门诊第 6 次起就诊自付 20%（指定的 PCP、互联网问诊和慢病送药不计入门诊次数，Medical 保费下调 6%）；柏盛 PCP 首诊直付服务（急诊除外，Medical 保费下调 3%）；最高等级 FMU（11EE 以下全员个人健康告知、不承担一切既往症，Medical 保费下调 5%）。三项医疗折扣可以按选择叠加，调整后 Medical 费率、折扣金额与最终个人保费均按人民币整元向上取整。

- 计划模型仅保留 `P3WWE`、`P4WWE`、`P4WW` 的正式 Plan 3/Plan 4 区域组合，并为每个计划保留 `code`、`group`、`area`、`rateColumn`、`outpatientMaximum` 和源表定位信息。
